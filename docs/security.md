# Security and Acceptable Use

Qwen3.8-Cyber-AI is an educational project for defensive cybersecurity learning.

## Authorized use only

Use the assistant with systems, networks, accounts, and data that you own or are explicitly authorized to assess. Keep practical exercises inside isolated labs or approved training environments.

## Prohibited use

Do not use this project to:
- Access systems or accounts without permission.
- Steal, guess, harvest, or expose credentials.
- Create or deploy malware, ransomware, or destructive payloads.
- Evade detection or maintain unauthorized access.
- Disrupt services or damage data.
- Conduct phishing or social engineering against real people.

## Protect sensitive information

- Never paste passwords, API keys, access tokens, private keys, recovery codes, or confidential customer data into the chat.
- Do not commit secrets to the repository.
- Use environment variables or a dedicated secret manager for credentials.
- Keep Gradio share links private and temporary.
- Review logs and notebook outputs before sharing them.

## Model limitations

Model output may be inaccurate or incomplete. Verify commands and security recommendations before applying them. Test changes in a disposable lab or staging environment first.

## Reporting a vulnerability

Do not publish exploitable details about a live system. Contact the repository maintainer privately with a concise description, impact, and safe reproduction steps that do not expose third-party data.
